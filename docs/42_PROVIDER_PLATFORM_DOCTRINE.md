# Provider Platform Doctrine

The provider doctrine applies uniformly across Neptlium Capital, Treasury, Pay, Forge, Admin and API.

A specialized surface may emphasize a different capability, but it may not create a different financial authority model.

- Capital sees governed/reconciled capital state.
- Treasury sees organization-scoped intents, policy, approvals and reconciled movement.
- Pay exposes governed money-movement experiences and APIs.
- Forge exposes Neptlium contracts and sandbox/developer infrastructure.
- Admin operates authorized controls and reconciliation exceptions.
- API/Platform Core owns provider orchestration and canonical financial controls.

Circle, Alchemy and Stripe remain infrastructure below this product model.
