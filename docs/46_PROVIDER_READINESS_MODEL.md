# Provider Readiness Model

Readiness is operation-specific.

**Observation readiness** requires a certified observation capability plus the applicable connectivity/certification gates. It does not require or imply economic execution.

**Execution readiness** requires a certified capability whose execution flag is explicitly enabled plus the execution-authorization gate. Runtime execution still requires the specific Neptlium authorization/policy/approval context.

This allows Alchemy to be production-ready for multi-chain observation while remaining incapable of financial execution, and allows Circle/Stripe to be connected or certified for selected operations without globally enabling money movement.
