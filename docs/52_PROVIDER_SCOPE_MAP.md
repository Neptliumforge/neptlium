# Provider Scope Map

```text
NEPTLIUM PLATFORM CORE (AUTHORITATIVE)
  identity / ownership / authorization
  policy / risk / approvals
  intents / lifecycle
  canonical ledger
  reconciliation / audit

CIRCLE (INFRASTRUCTURE)
  stablecoin / wallet / settlement capabilities

ALCHEMY (INFRASTRUCTURE)
  multi-chain RPC / observation / events / simulation

STRIPE (INFRASTRUCTURE)
  fiat / cards / bank payments / billing
```

Cross-provider evidence is correlated by Neptlium-owned identifiers. No provider can promote its own observation into canonical financial truth.
