# Neptlium Web Design Authority — compatibility reference

**Status:** Superseded as an independent authority.

The canonical Neptlium design authority is **docs/03_DESIGN_SYSTEM.md**.
The runtime token authority is **packages/ui/src/styles/tokens.css**.

This file remains only so historical links do not silently break. It MUST NOT be used to introduce a second palette, typography scale, surface system, route hierarchy, navigation model, spacing system or component authority.

## Canonical public product language

Neptlium is the **Capital Operating Platform**.

Primary capability hierarchy:

1. Capital
2. Portfolio
3. Investments
4. Treasury
5. Intelligence
6. Infrastructure

Supporting expressions: Institutional, Security, Insights and Company.

Legacy `/personal` converges to `/capital`; legacy `/business` converges to `/treasury`. They are not competing product identities.

## Web-specific composition

Public Web uses the canonical shared tokens and Capital Rails while retaining editorial marketing density. The opening header and hero belong to one Deep Capital Environment. Light environments may be used deliberately for explanation and trust, but do not establish an independent palette.

Marketing establishes category, meaning and product language. It does not establish financial, provider or backend authority.

For current rules covering mark geometry, mineral-teal semantics, black depth, light environments, typography, spacing, motion, Capital Rails, accessibility, responsive behavior, themes and financial-state presentation, read `docs/03_DESIGN_SYSTEM.md`.
