# Provider Target State

The target state is a provider-neutral Neptlium control plane where Circle, Alchemy and Stripe can be configured, observed, degraded, disabled, replaced or expanded without changing canonical financial authority.

Alchemy operates across a Neptlium-owned multi-chain registry. Circle supplies certified stablecoin/wallet/settlement capabilities. Stripe supplies certified fiat/payment/billing capabilities. Platform Core governs every consequential lifecycle and reconciles external evidence into the canonical ledger.

No provider is globally enabled. Capabilities are independently certified and released.
