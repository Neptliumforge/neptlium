# HISTORICAL / NON-AUTHORITATIVE — Neptlium Marketing Design Doctrine

> **Historical record only.** This document preserves a superseded dark-first marketing implementation doctrine. It is not current design authority. `docs/03_DESIGN_SYSTEM.md` is the sole authoritative `03` design document and overrides this file on identity, palette, typography, motion, surface behavior, product alignment, and governance.

## Historical scope

The legacy doctrine described the six-composition public marketing structure, a dark-first palette, marketing-local tokens, navigation behavior, motion timings, responsive targets, and implementation-era conversion copy.

The current design system retains only compatible principles: marketing may be more editorial and dimensional than the authenticated application; typography and composition carry hierarchy; accessibility and reduced-motion behavior are mandatory; public surfaces must preserve truthful metadata and never fabricate customers, balances, providers, certifications, regulation, settlement, or live financial capability.

The following legacy implementation details are intentionally **not authoritative** and must not be reintroduced from this archive without a new architecture/design decision:

- dark-first-only theme requirements;
- legacy marketing-local palette ratios and token ownership;
- old typography guidance that predates the unified typography contract;
- fixed motion-duration doctrine;
- implementation-history CTA/navigation copy;
- any rule that competes with the unified marketing/application identity in `docs/03_DESIGN_SYSTEM.md`.

For current work, read `docs/03_DESIGN_SYSTEM.md` and the relevant application source instead of this archive.
