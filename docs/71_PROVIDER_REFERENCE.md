# Provider Reference

| Provider | Canonical role | Never owns |
| --- | --- | --- |
| Circle | Stablecoin/digital-money wallet and settlement infrastructure | Neptlium authorization, canonical balance/ledger, reconciliation |
| Alchemy | Multi-chain blockchain connectivity, observation and intelligence | Financial authorization/execution, canonical balance/ledger, reconciliation |
| Stripe | Fiat/card/bank-payment and billing infrastructure | Neptlium account model, authorization, canonical balance/ledger, reconciliation |

Platform Core remains the authority for identity/ownership, authorization, policy/risk/approvals, intents, ledger, reconciliation and audit.
