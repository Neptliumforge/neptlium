# Provider Doctrine

Neptlium uses Circle for reviewed stablecoin/digital-money/wallet/settlement infrastructure, Alchemy for reviewed multi-chain blockchain connectivity/observation/intelligence, and Stripe for reviewed fiat/payment/billing infrastructure.

All three are replaceable capability adapters below Neptlium Platform Core.

Neptlium owns identity resolution, ownership, authorization, policy, risk, approvals, transaction intents, canonical ledger, reconciliation, audit and final financial truth.

Configured is not certified. Supported is not enabled. Authorized is not settled. Settled is not reconciled. Provider evidence is not canonical ledger truth.
