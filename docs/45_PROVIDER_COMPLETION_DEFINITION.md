# Provider Completion Definition

Provider integration is not complete when credentials are added or an SDK request succeeds.

For a read-only capability, completion means configuration, authentication, normalization, evidence integrity, observability and failure behavior are certified for the specific environment/network/rail.

For an execution capability, completion additionally requires Neptlium intent identity, ownership/authorization, policy/risk/approvals, idempotency, ambiguous-outcome recovery, settlement definition, canonical ledger posting, reconciliation, audit, operational disable controls and explicit production authorization.

Completion is capability-specific. Circle transfer completion does not certify wallet provisioning. Alchemy Base observation does not certify Ethereum observation. Stripe billing does not certify capital funding.
