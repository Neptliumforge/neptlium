# Provider Doctrine Freeze

The architecture doctrine for this slice is frozen as follows:

**Circle = stablecoin/digital-money wallet and settlement infrastructure.**

**Alchemy = multi-chain blockchain connectivity, observation and intelligence infrastructure.**

**Stripe = fiat/card/bank-payment and billing infrastructure.**

**Neptlium Platform Core = financial authority: identity/ownership, authorization, policy, intents, canonical ledger, reconciliation and audit.**

No additional primary provider role or financial authority transfer should be introduced in this slice. Runtime migration and production certification are subsequent gated executions.
