# Neptlium Global Product System

Marketing explains the capital operating system.

The application operates the capital operating system.

Both speak with one visual and editorial language.

## Shared identity

The shared expression is black authority, deep green structure, indigo intelligence, and neutral comprehension. Indigo is a signal for focus, selected state, and high-value action—not a broad surface identity.

`packages/design-system/src/neptlium-tokens.css` is the shared semantic token source. `apps/app` may provide operational aliases and its optional light-theme extension; `apps/web` maps public-site utilities to the same vocabulary. Raw values belong in the token source or static image assets only.

## Typography and geometry

Both products use the same offline system-first stack and mono fallback. Marketing uses editorial display roles and wider reading measures. The app uses compact page/panel/component roles and denser operating layouts. Buttons are 40px by default, 44px for primary actions; inputs are at least 44px; standard panels use 20–24px padding.

The canonical mark is two opposing trapezoids around a centered ring. Use the same geometry in the web header, footer, favicon, metadata image, app shell, and auth. Do not introduce alternate monograms or gradients.

## Product distinction

The public site explains the architecture, product vocabulary, and capability boundaries. It does not simulate funded accounts, live markets, financial performance, or enabled infrastructure. The authenticated application presents verified account state and operations. Both use direct state language: Available, Unavailable, Restricted, Provider not configured, Account provisioning required, Capability disabled, and No recorded activity.

## Editorial and interaction rules

Use sentence case, direct active wording, one primary message per surface, visible focus, reduced-motion support, and 4px-aligned rhythm. Avoid “coming soon,” exchange/trading language, unsupported capability claims, decorative glows, blue hero washes, and card-heavy grids. Public CTAs route directly to `app.neptlium.com/auth/sign-in` or `app.neptlium.com/auth/sign-up`.

## Responsive and accessibility baseline

Use 16px mobile gutters, 24px tablet gutters, and 32–48px desktop gutters with bounded wide-screen content. Keep touch controls at least 44px where primary/mobile, expose semantic landmarks and headings, retain keyboard/escape/focus restoration behavior, and ensure status text is meaningful without color.
