# Provider Executive Contract

Neptlium uses external providers to extend capability without surrendering financial authority.

Circle is the stablecoin/digital-money infrastructure adapter. Alchemy is the multi-chain blockchain observation/intelligence adapter. Stripe is the fiat/payment infrastructure adapter.

Neptlium owns identity, ownership, authorization, policy, transaction intent, canonical ledger, reconciliation and audit. Every provider is replaceable behind that control plane.

No provider configuration, dashboard status, webhook, RPC result, API response or transaction submission is sufficient by itself to establish customer-visible financial truth.
