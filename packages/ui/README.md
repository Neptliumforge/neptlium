# @neptlium/ui

Shared React components and application-shell primitives for Neptlium.

The package contains accessible controls, cards, navigation, layout primitives, theme tokens, and motion standards used by the authenticated platform and internal console.

```sh
pnpm --filter @neptlium/ui typecheck
pnpm --filter @neptlium/ui lint
pnpm --filter @neptlium/ui build
```

Import components from `@neptlium/ui` and global tokens from `@neptlium/ui/styles/tokens.css`.
